نظام إدارة عيادة الأسنان — الحل المجمّع
=========================================

تطبيق Windows Forms لإدارة المرضى والأطباء والمواعيد والعلاجات، مع طبقة بيانات
مشتركة محلية ورسم بياني بلوحة التحكم باستخدام GDI+.

المشاريع (جميعها .NET Framework 4.7.2)
---------------------------------------
1) LoginDashboard  — LoginForm وDashboardForm وReportsForm (مشروع البدء)
2) Patients       — MainForm (صفحة المرضى)
3) Appointments   — AppointmentsForm
4) Doctors        — DoctorsForm
5) Treatments     — TreatmentForm

الكود المشترك
-------------
مجلد Shared يحتوي ملفات مصدرية مرتبطة (Linked) بكل مشروع، أي أن نفس الكود
يُترجم داخل كل تجميعة (Assembly):

- ClinicData.cs       نماذج البيانات + ClinicStore للتخزين والتحقق والدوال المساعدة
- UiTheme.cs          الألوان والخطوط وتنسيق الجداول والأزرار وحقول البحث
- BarChartPanel.cs    رسم بياني GDI+ (حواف ناعمة، أعمدة متدرجة دائرية)
- RecordEditorForm.cs نافذة إضافة/تعديل موحّدة مع تحقق من المدخلات

طريقة الفتح والتشغيل
--------------------
1. افتح DentalClinic_Combined.sln باستخدام Visual Studio 2022.
2. اجعل LoginDashboard هو مشروع البدء (Startup Project).
3. ابنِ المشروع (Debug أو Release) ثم شغّله.

بيانات الدخول
-------------
اسم المستخدم: admin
كلمة المرور: admin123

تخزين البيانات
--------------
تُحفظ البيانات في ملف مركزي واحد تشترك فيه كل الشاشات:

  %LOCALAPPDATA%\DentalClinicMS\clinic-data.txt

- يُنشأ تلقائيًا ببيانات تجريبية واقعية عند أول تشغيل.
- كل إضافة/تعديل/حذف تُحفظ فورًا، وكل شاشة تعيد تحميل الملف عند تنشيطها،
  وبذلك تبقى الصفحات متسقة.
- إذا كان الملف غير قابل للقراءة يُنسخ جانبًا باسم
  clinic-data.corrupt-yyyyMMddHHmmss.txt ثم تُنشأ بيانات جديدة.
- خذ نسخة احتياطية من هذا الملف قبل نقل التطبيق إلى جهاز آخر.

المزايا
-------
- تسجيل دخول مع تحقق ورسائل خطأ داخل النموذج وإظهار/إخفاء كلمة المرور.
- لوحة التحكم: ساعة حية تتحدث كل ثانية، التاريخ الصحيح، إحصاءات حقيقية،
  رسم بياني GDI+ لتوزيع حالات المواعيد، المواعيد القادمة، وإجراءات سريعة.
- المرضى: المعرف والاسم وتاريخ التسجيل والعمر والجنس والعنوان والحالة؛
  إضافة/تعديل/حذف، بحث بمعرف المريض أو الاسم، مسح الفلتر، وعدّاد للنتائج.
- الأطباء: إضافة/تعديل/حذف، بحث بالاسم/التخصص/الهاتف، قائمة فلترة بالأسماء،
  ومسح الفلتر.
- المواعيد: إضافة/تعديل/حذف، بحث بمعرف المريض أو اسم الطبيب أو التاريخ؛
  قوائم للمرضى والأطباء والعلاجات، فترات زمنية، منع حجز نفس الطبيب في نفس
  الوقت، ومنع التواريخ الماضية للمواعيد الجديدة.
- العلاجات: إضافة/تعديل/حذف، بحث باسم العلاج، مسح الفلتر، والتحقق من
  السعر والمدة والحالة.
- التقارير: فلترة بنطاق تاريخ وطبيب، إجماليات المرضى/المواعيد/العلاجات
  المستخدمة/الإيرادات، وملخص شهري محسوب من البيانات الفعلية.
- حماية العلاقات: لا يمكن حذف مريض أو طبيب أو علاج مرتبط بمواعيد حتى
  تتم معالجة تلك المواعيد أولًا.

ملاحظات وحدود
-------------
- تخزين محلي أحادي المستخدم (ملف نصي) وليس خادم قاعدة بيانات.
- فترات المواعيد كل 30 دقيقة من 09:00 إلى 16:30.
- الإيرادات تُحسب من المواعيد بحالة Completed فقط.
- كل مشروع ما زال يحتوي Program.cs ويمكن تشغيله منفردًا، أما لوحة التحكم
  فتشغّل الشاشات كأبناء داخل نافذة موحّدة.

البناء
------
إعدادا Debug وRelease يبنيان الحل كاملًا:

  MSBuild DentalClinic_Combined.sln /t:Build /p:Configuration=Debug
  MSBuild DentalClinic_Combined.sln /t:Build /p:Configuration=Release
